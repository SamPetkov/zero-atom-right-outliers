# Contributing

Corrections are welcome through focused issues or pull requests.

A mathematical correction should identify the exact theorem, equation, or proof step; state whether the issue is fatal, repairable, or expository; and include a concrete counterexample or replacement lemma where possible. Numerical changes should preserve deterministic seeds or clearly document new seeds and environments.

By contributing, you agree that prose, LaTeX, figures, and data are licensed under CC BY 4.0 and that code contributions are dual-licensed under CC BY 4.0 and MIT.
