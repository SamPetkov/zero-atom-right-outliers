# PRL submission checklist

## Scientific responsibility

- [ ] Samuil Petkov has independently checked every theorem and source citation.
- [ ] The marked extension of the source theorem has been reviewed by a specialist.
- [ ] The manuscript is identified as a preprint until peer review is complete.
- [ ] Any mathematical changes after review are propagated to the Letter, supplement, report, and code.

## APS package

- [x] Main manuscript is a single REVTeX 4.2 PDF.
- [x] Supplemental Material is a separate, self-contained PDF.
- [x] The main manuscript cites the supplement as a numbered reference.
- [x] Every reference used by the supplement is also present in the main reference list.
- [x] Reference titles are included consistently.
- [x] One-paragraph, self-contained abstract with no numbered citations.
- [x] Data availability statement after the Acknowledgments.
- [x] Substantive AI assistance disclosed with tool, role, direction, and verification.
- [x] 100-word editorial justification prepared.
- [x] Cover letter prepared.
- [ ] Corresponding-author ORCID added in the APS submission system.
- [ ] Appropriate PhySH terms selected.
- [ ] Repository made public and, preferably, archived with a persistent DOI before acceptance.
- [ ] Data availability citation updated from a GitHub URL to the final persistent identifier if one is minted.

## Technical validation

- [x] Main PDF visually inspected page by page.
- [x] Supplemental PDF visually inspected page by page.
- [x] Bibliography resolved with no undefined citations.
- [x] Deterministic numerical verification script passes.
- [x] Fixed seed and exact package versions recorded.
- [ ] GitHub Actions pass after publication.
